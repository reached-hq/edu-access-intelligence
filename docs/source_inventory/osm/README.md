## Why it might matter

Provides geographic features that can support school-location and geographic accessibility analysis for the Education Access Intelligence project.

OSM school features can provide geographic reference points for schools, while road features can support distance- or proximity-based accessibility analysis.

## What we expect it to contain

The GeoPackage contains multiple OpenStreetMap feature layers.

The current profiling scope includes:

- `gis_osm_pois_free` — points of interest, including features classified as schools
- `gis_osm_roads_free` — road features

The school features are expected to provide OSM identifiers, names, classifications, and point geometries.

The road layer is expected to provide OSM identifiers, classifications, names, road attributes, and line geometries.

These expectations were verified against the source during profiling where applicable.

## Important limitations

- OSM school features are not the official Philippine school inventory.
- The current extract contains 3,572 OSM features classified as `school`; this should not be interpreted as the total number of schools in the Philippines.
- OSM school coverage may differ from DepEd records.
- OSM and DepEd school records require a downstream matching process before they can be combined.
- Road `maxspeed` is unavailable or unspecified for most road records in the profiled extract. Therefore, the source should not be treated as sufficient for nationwide road-based travel-time estimation.
- OSM will primarily support geographic proximity or distance-based accessibility analysis.

## Intended use

OSM will be used as a supporting geographic source.

- **School locations:** geographic reference for spatial analysis and matching with DepEd school records.
- **Road features:** supporting geographic proximity or distance-based accessibility analysis.
- **Official education attributes:** DepEd remains the authoritative source for school inventory, enrollment, personnel, facilities, and other official education attributes.

Spatial matching and derived accessibility measures are downstream transformations and are not part of source profiling.
