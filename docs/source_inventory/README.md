# Source inventory

One card per source, created by copying [`_template.md`](_template.md) to `<source_id>.md`.

Rules:

- A source is not described as useful until it has been inspected.
- Any field not yet confirmed is written as `UNVERIFIED`, not guessed.
- Each card's `source_id` matches its entry in [`config/sources.json`](../../config/sources.json).
