# LGU education planner needs

What LGU education planners need to decide, taken from published documents (D-001). The stakeholders are LGU planners, with students as the focus (D-013). Each need is tagged:

- **documented**: stated in a cited document (document and page below)
- **mentor-validated**: confirmed by the program mentor (none yet; see [Questions for the mentor](#questions-for-the-mentor))
- **assumed**: needed by Question v1 but not found in the documents read

The "Question v1" column links each need to the analytical questions (AP1 to AP5) in `docs/business_analytics_problem.md` (#9, PR #64).

## Thresholds and standards

No threshold, standard or ideal ratio is used here unless quoted from a cited document.

- JC 1-2025 Annex B (p. 26) and the Playbook (p. 23) refer to an "ideal classroom-to-student ratio" without giving a number. Question v1 does not set one.
- EDCOM Y2 (p. 128 [PDF 124]) describes DepEd Order 29 (2003), which colour-coded schools by students per classroom: "blue" at 45 or less up to "red" at 56 or more. This is a historical prioritization rule, quoted here for context only. It is not adopted as a threshold.
